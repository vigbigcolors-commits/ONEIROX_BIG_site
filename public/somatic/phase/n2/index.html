Why N2 gets its own hub

N2 is the sigma window (11–16 Hz): spindles, K-complex, bruxism, periodic limb movements, pre-REM atonia ramp. The readout is muscle and EEG — not a symbol dictionary. This hub is not a blog about “N2 dreams.” It is the index of 2 high-density metric utilities currently allowed to crawl. Each card is a different symptom × N2 × context triple. Same phase, different hardware. Mixing N1/N2/N3/REM into one omen paragraph is how thin pages get born; this URL refuses that mix.

Contexts present in the live N2 index: fragmentation, mid-cycle. Symptom families: Periodic limb movements in sleep, Sleep-related bruxism (jaw clenching). If two links look similar, read the context suffix — onset is not awakening; fragmentation is not mid-cycle. Cortical language for this stage stays inside N2 physiology, not a personality metaphor.

This N2 hub is intentionally small. Dense-gate is stricter than “cover the keyword.” Right now 2 rows pass. Periodic limb movements in sleep in N2 sleep (fragmentation) is the live example: use it if the waking body matches; do not pad the hub with thin cousins. When more N2 rows earn markers + context + a 17-character-class bind (for somatic: example-complete fields), they appear here via drip, not by hand.

Slow-wave / N2 nights are easy to misread as “nothing happened” because recall is poor. That is why a single motor-residue row still deserves a hub: confusional arousal leftover, stillness, or N3-exit jerks are stage-shift hardware. If your night was vivid story, you were probably not in N2 for the remembered scene — check REM or N2 hubs instead of forcing this URL.

How to work a night that belongs on this hub: 1) write the first twenty seconds of residue (heat, weight, mute, twitch, jaw, breath). 2) pick the N2 card whose title names that residue. 3) read that row’s gauges and markers — numbers are URL-specific. 4) carry the row into Lab Search; do not paste a symbol. 5) if the night was mostly plot, use Dream Meaning; if it was mostly body, stay in /somatic.

N2 is a sleep-architecture label, not a type of person. N1 is a theta gate into sleep, N2 a sigma/spindle window, N3 a delta well, REM a dreaming state with spinal atonia. This page only lists N2. Neighbor hubs: N1, N2, N3, REM.

What this hub will not do: diagnose apnea, REM sleep behavior disorder, or psychiatric disease. Persistent dream enactment, choking, or daytime collapse needs a clinician. What it will do: keep N2 metrics honest so Decode is not guessing from a plot summary. Methodology lives on About; Lab Notes by Vigen sit at /notes.
