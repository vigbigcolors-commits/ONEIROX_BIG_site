Why N3 gets its own hub

N3 is delta (0.5–2 Hz). Confusional motor residue at N3-exit is a stage-shift in the body, not a story the cortex finished telling. This hub is not a blog about “N3 dreams.” It is the index of 1 high-density metric utilities currently allowed to crawl. Each card is a different symptom × N3 × context triple. Same phase, different hardware. Mixing N1/N2/N3/REM into one omen paragraph is how thin pages get born; this URL refuses that mix.

Contexts present in the live N3 index: awakening. Symptom families: Confusional arousal motor residue (N3 exit). If two links look similar, read the context suffix — onset is not awakening; fragmentation is not mid-cycle. Cortical language for this stage stays inside N3 physiology, not a personality metaphor.

Slow-wave / N3 nights are easy to misread as “nothing happened” because recall is poor. That is why a single motor-residue row still deserves a hub: confusional arousal leftover, stillness, or N3-exit jerks are stage-shift hardware. If your night was vivid story, you were probably not in N3 for the remembered scene — check REM or N2 hubs instead of forcing this URL.

How to work a night that belongs on this hub: 1) write the first twenty seconds of residue (heat, weight, mute, twitch, jaw, breath). 2) pick the N3 card whose title names that residue. 3) read that row’s gauges and markers — numbers are URL-specific. 4) carry the row into Lab Search; do not paste a symbol. 5) if the night was mostly plot, use Dream Meaning; if it was mostly body, stay in /somatic.

N3 is a sleep-architecture label, not a type of person. N1 is a theta gate into sleep, N2 a sigma/spindle window, N3 a delta well, REM a dreaming state with spinal atonia. This page only lists N3. Neighbor hubs: N1, N2, N3, REM.

What this hub will not do: diagnose apnea, REM sleep behavior disorder, or psychiatric disease. Persistent dream enactment, choking, or daytime collapse needs a clinician.
